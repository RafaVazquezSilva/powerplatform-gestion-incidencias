# Base documental (ficticia)

Seis documentos internos inventados de **AudioVital**, indexados en Azure AI Search para que el asistente responda fundamentado en ellos y cite la fuente. Los criterios de prioridad son los mismos que aplica el clasificador del Flujo 1, de modo que asistente y clasificación se rigen por una única fuente.

| Documento | Contenido |
|---|---|
| `procedimiento_averias.pdf` | Criterios de prioridad de averías (Alta, Media, Baja) |
| `politica_reclamaciones.pdf` | Prioridades de reclamación; umbral de 150 € para aprobación de supervisor |
| `protocolo_escalado.pdf` | Reglas de escalado y plazos del supervisor |
| `cambios_citas.pdf` | Cambios y cancelaciones de citas |
| `garantia_productos.pdf` | Garantías por categoría de producto y exclusiones |
| `protocolo_atencion_cliente.pdf` | Protocolo general de atención; prohibición de exponer campos internos |

*Documentos creados exclusivamente para este proyecto. No corresponden a ninguna empresa real.*
